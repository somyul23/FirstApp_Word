# 📱 FirstWord

## 📌 소개

SwiftUI를 사용하여 개발한 iOS 단어장 애플리케이션입니다.
사용자가 단어를 추가하고, 검색 및 테스트 기능을 통해 효율적으로 학습할 수 있도록 설계했습니다.

---

## 🚀 주요 기능

### 📚 단어장 관리

* 단어장 생성, 삭제, 이름 변경
* 여러 단어장 관리 가능

---

### ➕ 단어 추가

* 단어, 뜻, 발음, 예문 입력 가능

---

### 🔍 검색 기능

* 단어 / 뜻 / 발음 기준 검색
* 현재 선택된 단어장 기준으로 필터링

---

### 📝 테스트 기능

* 객관식 / 주관식 2가지 테스트 제공
* 문제와 답을 아래 항목 중에서 선택 가능:

  * 단어
  * 뜻
  * 발음
* 다양한 조합으로 학습 가능 (예: 단어 → 뜻, 뜻 → 단어 등)

---

### 🎨 UI 및 기타

* 다크모드 지원
* SwiftUI 기반 UI 구현

---

## 🛠 기술 스택

* Swift
* SwiftUI
* MVVM 패턴
* Local Data Storage

---

## 💡 구현 포인트

* SwiftUI의 상태 관리(@ObservedObject)를 활용한 데이터 흐름 설계
* 현재 선택된 단어장 기준으로 검색 필터링 기능 구현
* fullScreenCover를 하나로 통합하여 성능 문제 해결
